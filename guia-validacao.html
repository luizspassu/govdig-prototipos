Abrir protótipo ↗
Preparação rápida antes de apresentar

Abra este guia e o protótipo em abas diferentes, no mesmo navegador. Use um único produto em todo o percurso. Confira a versão 0.5.25. Não reinicie a simulação, pois isso apaga dados locais. Se o produto sugerido já foi usado, adote um nome novo. Use outubro/2026 e 2026-T4 em todo o exemplo. A barra fina troca os perfis apenas para a demonstração; ela não representa autenticação real.

GO → SM → INOV → CONSUL → Sistema → SM → INOV → CONSUL → vínculo no trimestre → agrupamento anual → fechamento
